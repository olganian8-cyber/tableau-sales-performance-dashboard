# Sales Performance Analysis | Tableau Dashboard

## Project Overview
Developed an interactive Tableau dashboard to analyze sales, profit, and order quantity across different product categories and geographic locations. The dashboard allows users to monitor business performance, compare yearly results, and identify key trends.

## Project Objectives
- Analyze sales, profit, and quantity performance.
- Compare current-year and previous-year results.
- Identify the highest and lowest performing months.
- Evaluate performance across product subcategories.
- Monitor weekly sales and profit trends.

## Tools Used
- Tableau Desktop
- Calculated Fields
- Data Visualization
- Business Intelligence
- KPI Analysis

## Dashboard Features
**1. KPI Analysis:** Created sales, profit, and quantity indicators with year-over-year percentage comparisons.

**2. Monthly Trends:** Developed line charts to compare current-year and previous-year performance and highlight maximum and minimum values.

**3. Subcategory Analysis:** Built charts to compare sales and profitability across product subcategories.

**4. Weekly Trends:** Visualized weekly sales and profit performance using reference lines to identify above-average and below-average results.

**5. Interactive Filters:** Enabled analysis by year, category, subcategory, region, state, and city.

## Business Value
This dashboard helps users monitor business performance, identify trends, assess product profitability, and support data-driven decision-making.
